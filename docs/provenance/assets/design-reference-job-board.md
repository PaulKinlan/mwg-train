# Provenance: job-board archetype visual reference board

- **Scope:** one illustrative JPEG for `job-board`, an in-family training archetype (`tr-12` with the `fam-12` biotech-research variant, one of the sixteen in `src/eval/prereg.mjs`) rather than one of the five evaluation families. It exists because the archetype's plan asserts a posting-refusal contract - submitting a new vacancy without the mandatory job title and contact email is refused with specific inline validation messages - and the board set for that state was empty (`mwg-train-ko9i`, per [`reference-board-gaps.md`](reference-board-gaps.md)). This record exists so nobody has to guess which side of the boundary it sits on: **A1, planning reference only** - not an evaluation target, not a training example, not generated-site evidence.
- **Generation:** 2026-10-13 UTC, by `scripts/generate-archetype-boards.mjs --write --only job-board`. The script passes `model: gemini-nano-banana-2.1` explicitly to the project's model gateway (`https://gemini.int.exe.xyz/v1beta/models/gemini-nano-banana-2.1:generateContent`, overridable with `MWG_TRAIN_IMAGE_ENDPOINT`) and fails closed unless the response's own `modelVersion` equals the requested model, so the board is gateway-attested `gemini-nano-banana-2.1`. Recorded settings: `responseModalities: ["IMAGE"]`, temperature 0.7, `maxOutputTokens` 8192; the board returned a 1376 × 768 JPEG. No seed was set, so the bytes are not reproducible from the prompt. The prompt is the one in the linked archetype README, and its exact UTF-8 digest is in the table below, so a regeneration can be proven to have used the same brief.
- **Rights:** [Google consumer-account terms](../accounts/google-antigravity-consumer.md) prohibit using AI-generated service content to develop machine-learning models. `excluded_from_training: true`; `approved_for_training: false`. No exclusive copyright, general image license, production or commercial reuse clearance is claimed, and no separate reuse/clearance document was supplied. Do not move this image into a corpus, an evaluation target, adapter or training work, or generated-site evidence. A visual review does not change that boundary.
- **Visual truth:** the board name, vacancy vocabulary, field labels and error strings are invented, unverified placeholders. The JPEG does not demonstrate a working search, posting flow, dashboard or validation engine, and it does not by itself satisfy the archetype's contract: the refusal behaviour is asserted by the plan and its verifiers, not by this picture.
- **Observed placeholder artefacts, inspected and accepted:** an independent vision review of this 2026-10-13 board (commissioned from a vision-capable model in a different family than the lane that produced it, which is text-only) returned ACCEPT. It quoted the banner "The vacancy was not posted" (with subtext "Please correct the highlighted errors below before resubmitting.") and both inline messages ("Job title is required", "A contact email is required"), and pixel-scanned the error styling: red is confined to the two named fields (Job Title 6.6%, Contact Email 7.0% reddish-pixel fraction) while the correctly-filled Laboratory Location, Salary Range and Requirements fields measure 0.00% red and keep their values (Boston, MA (On-site); $95,000 - $120,000 USD; three requirement bullets). No corrupted text in any primary position. A "Dashboard / Post a Vacancy" breadcrumb is the only dashboard mention; the main content is the refusal form. This record does not imply the board was clean beyond what that review quoted.
- **Coverage:** one board, for the posting-refusal state only. The listing, vacancy, application, filtered and empty states are **not** pictured and must not be inferred from this image.
