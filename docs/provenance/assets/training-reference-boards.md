# Provenance: training-family visual reference boards

- **Scope:** 30 illustrative JPEGs, one per training family (`tr-01`..`tr-30`), under [`docs/design/training/<family>/reference.jpg`](../../design/training). They are visual planning references for the training families - what a finished, production-quality version of each family's site should look like. They are **not** functional interfaces, **not** generated-site screenshots, **not** corpus or training data, and **not** the sealed A6 evaluation targets. The A1 conformance instrument is a different file: [`training-targets.md`](training-targets.md), `data/A1_self_generated/targets/<family>/target.png`, which stays a render of the authored board.
- **Generation:** regenerated 2026-10-11 by [`scripts/generate-training-boards.mjs`](../../../scripts/generate-training-boards.mjs), which requests `gemini-nano-banana-2.1` explicitly through the project's model gateway (`https://gemini.int.exe.xyz/v1beta/models/gemini-nano-banana-2.1:generateContent`, overridable with `MWG_TRAIN_IMAGE_ENDPOINT`) and **fails closed unless the response's own `modelVersion` equals the requested model**. Recorded settings: `responseModalities: ["IMAGE"]`, temperature 0.7, `maxOutputTokens` 8192; each board is generated in one 1376×768 16:9 frame. The attestation is a property of the gateway's own response, not a cryptographic proof about the pixels, and no seed was set: the bytes are not reproducible from the same prompt.
- **Prompts:** The boards were generated from an earlier prompt revision. The current canonical prompts are composed deterministically from each family's own committed sources - its canonical (`-v1`) row in [`docs/train/briefs/manifest.jsonl`](../../train/briefs/manifest.jsonl), its [`plan.md`](../../train/design) routes, journeys and fields, and its `design.md` palette, typography and anti-patterns. Every prompt names the RECORDED date `11 October 2026` as today and asks for every event after it: the second batch, asked for "the near future" without being told when now was, dated twenty boards in 2023 and 2024. Composing rather than hand-writing means the owner's own description of the site is in every prompt verbatim, and the art direction is the family's own `design.md` rather than a shared template.
- **Rights:** [Google consumer-account terms](../accounts/google-antigravity-consumer.md) prohibit using AI-generated service content to develop machine-learning models. These boards are **not** corpus material: `excluded_from_training: true`, `approved_for_training: false`, and in kind `A3_teacher_generated` - teacher-model output quarantined from training and published only as planning documentation. No exclusive copyright, general image licence or production/commercial reuse clearance is claimed. Do not move these images into the corpus, the evaluation targets, training or adapter work, or generated-site evidence. Visual review does not change that boundary. The generator refuses any write outside `docs/`, so this cannot happen by running the script.
- **Visual truth:** every product, price, address, name, date, quantity and control label inside a board is an invented placeholder produced by the model. Nothing in these images verifies a route, a state, an email, a payment or a booking, and a depicted success or confirmation state is not a claim that one is implemented. Only the bytes and the prompt arguments are pinned here.
