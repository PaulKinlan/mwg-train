# Provenance: Wave 2 archetype visual reference boards

- **Scope:** nine illustrative JPEGs across `catalogue`, `contact-lead`, `account-recovery` and `event-registration`. They are visual planning references, not functional interfaces, real transactions, generated-site screenshots, training examples or sealed A6 targets.
- **Generation:** 2026-10-09 UTC, nine Google Antigravity OAuth `generate_image` calls between 19:19 and 19:21 UTC. Each call requested `aspectRatio: "16:9"` and saved a 1376 × 768 JPEG to a local journal checkout before handoff. The generating lane reported `gemini-3-pro-image`; the calls omitted the optional `model` argument and returned output paths, not model attestations. Exact tool-call prompt strings (including literal escaping) appear in the four linked archetype READMEs. No endpoint, random seed or deterministic replay guarantee was supplied.
- **Rights:** [Google consumer-account terms](../accounts/google-antigravity-consumer.md) prohibit using AI-generated service content to develop machine-learning models. `excluded_from_training: true`; `approved_for_training: false` for **all nine**. No exclusive copyright, general image license or production/commercial reuse clearance is claimed. Do not move these images into corpus, evaluation targets, training, adapter work or generated-site evidence. Visual review does not change that boundary.
- **Visual truth:** invented products, addresses, prices, attendee identities, seat counts, reference tokens, QR graphics and UI control affordances are unverified placeholders. In particular, depicted success/confirmation states do not verify an email, payment, booking, real pass or accessibility behavior. Only the bytes and original prompt arguments are pinned here.
- **Coverage:** these are the nine actually supplied boards, not a complete error/empty/success set for every archetype. The catalogue includes an empty-search board; the other three families have only the two pictured steps. Missing error states must not be inferred or fabricated.
