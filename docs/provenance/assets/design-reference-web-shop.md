# Provenance: web-shop archetype visual reference board

- **Scope:** one illustrative JPEG for `web-shop`, an in-family training archetype (`tr-02`, one of the sixteen in `src/eval/prereg.mjs`) rather than one of the five evaluation families. It exists because the archetype's brief asserts an empty-cart contract - checkout prevented with an accessible alert and a path back to the catalogue - and the board set for that state was empty (`mwg-train-l9zm`, per [`reference-board-gaps.md`](reference-board-gaps.md)). This record exists so nobody has to guess which side of the boundary it sits on: **A1, planning reference only** - not an evaluation target, not a training example, not generated-site evidence.
- **Generation:** 2026-10-13 UTC, by `scripts/generate-archetype-boards.mjs --write --only web-shop`. The script passes `model: gemini-nano-banana-2.1` explicitly to the project's model gateway (`https://gemini.int.exe.xyz/v1beta/models/gemini-nano-banana-2.1:generateContent`, overridable with `MWG_TRAIN_IMAGE_ENDPOINT`) and fails closed unless the response's own `modelVersion` equals the requested model, so the board is gateway-attested `gemini-nano-banana-2.1`. Recorded settings: `responseModalities: ["IMAGE"]`, temperature 0.7, `maxOutputTokens` 8192; the board returned a 1376 × 768 JPEG. No seed was set, so the bytes are not reproducible from the prompt. The prompt is the one in the linked archetype README, and its exact UTF-8 digest is in the table below, so a regeneration can be proven to have used the same brief.
- **Rights:** [Google consumer-account terms](../accounts/google-antigravity-consumer.md) prohibit using AI-generated service content to develop machine-learning models. `excluded_from_training: true`; `approved_for_training: false`. No exclusive copyright, general image license, production or commercial reuse clearance is claimed, and no separate reuse/clearance document was supplied. Do not move this image into a corpus, an evaluation target, adapter or training work, or generated-site evidence. A visual review does not change that boundary.
- **Visual truth:** the shop name, product vocabulary, prices, the zero badge and every caption line are invented, unverified placeholders. The JPEG does not demonstrate a working catalogue, cart, checkout guard or accessible alert, and it does not by itself satisfy the archetype's contract: the empty-cart prevention behaviour is asserted by the brief and its verifiers, not by this picture.
