## Exact proposed image prompts

**Depicted copy is rendered product copy, not Markdown source.** Every string inside the pictured page is a surface a designer would ship: inspector section headings read as clean titles (“Description”, “Impact”) with no leading hashes, and code identifiers such as `spi_driver.c` sit in a monospace face with the backticks stripped. Literal heading hashes or backticks in the inspector read as an unstyled Markdown dump, not as a designed panel. The four committed boards predate this rule and do render Markdown source in the inspector; that gap is recorded as a known deviation in [PROVENANCE.md](PROVENANCE.md) rather than accepted.

Each block is a separate **1376 × 768 (16:9)** page-only JPEG request. Preserve the same Kestrel Sprint 24 release, KES-218 identity, palette and information architecture across all states. The visible page controls are not OS/browser controls. A still image cannot prove assignments, permissions, bulk mutation, View Transitions, form validation, keyboard operation or exported data.
