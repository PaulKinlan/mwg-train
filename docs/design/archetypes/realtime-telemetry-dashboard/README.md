## Exact proposed image prompts

Each block is its own **1376 × 768 (16:9)** full-page-only JPEG brief. The sample readings and B-07 identity remain visually consistent. “Simulation — not live” must be visible on every board; no invented measurement or acknowledgement may appear as an actual grid event. The stills can never prove working keyboard paths, source integrity, computed forecasts or physical derating.
