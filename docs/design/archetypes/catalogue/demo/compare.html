Visual design reference comparison

Each reference board from ../ beside the live page it informed, rendered in an iframe at a 1280 × 900 desktop viewport and a 390 × 844 mobile viewport.

The boards are the three JPEGs committed alongside this demo. Per ../README.md they are "visual planning references, neither generated-site captures nor sealed evaluation targets", and their products, prices, stock counts, totals and checkout buttons are "illustrative, unverified placeholders" that "do not prove a functional search, cart, checkout, responsive implementation or accessible controls".

Nothing on this page is a screenshot: the right-hand frames are the live files in this directory, loaded in an iframe, so no capture is committed and none can drift from the implementation. The left-hand images are the boards themselves, unmodified.

1. Product grid, search and filtering

Board ../step1-grid.jpg (1376 × 768, SHA-256 456797ff0d…) · live page index.html

Reference board

A 1376-wide board image; it is a planning reference, not a capture of a working page.

Live demo — 1280 × 900

Iframe viewport 1280 × 900, scaled to fit the column. Open it full size.

Live demo — 390 × 844

Iframe viewport 390 × 844, one column, chips wrapped.

  • Palette: page #0f172a, cards #1e293b, inset surfaces #162032, action emerald #10b981, muted text #94a3b8 — the values the board's generation prompt names.
  • Grid: one column below 34rem, two to 34rem, three from 60rem. The board renders five columns at its own width; the demo keeps its card anatomy (art → name → variant → price → stock → action) and lets the count follow the viewport instead of pinning five across.
  • Search: form#search-form with input[name=q] of type search labels itself "Search parts" and filters the twelve cards in place as you type; the query is echoed in the results line and in the empty state.
  • Chips: the board's category chips are drawn as aria-pressed toggle buttons; one category is active at a time and the grid narrows. A "Kiln parts" chip is added so the spec's bearing query has a real catalogue hit — the board's four chips have no such category.
  • Sort: the dropdown re-orders the same cards client-side by the board's four options (featured order, price each way, newest).
  • Stock states: "In stock", "Low stock — 3 left" and "Out of stock" are all rendered; the out-of-stock card's action is a disabled button described by its own pill, so the reason is never colour alone.
  • Art: twelve hand-drawn SVG shapes from one in-document sprite, toned by [data-tone] tokens. No image request, no web font, no CDN.

2. Slide-over cart drawer and order review

Board ../step2-cart.jpg (1376 × 768, SHA-256 4ae6bd190c…) · live page cart.html

Reference board

Two lines, subtotal £43.89: Artisanal Ceramic Tableware £19.99 and Rustic Vase £23.90.

Live variant — 1280 × 900

Iframe viewport 1280 × 900, scaled to fit. Open it full size.

Live variant — 390 × 844

Iframe viewport 390 × 844: the drawer takes the full width.

  • Drawer: a right-hand slide-over, 28rem wide and full width under 36rem, over a dimmed and blurred grid — the composition the board shows.
  • Line anatomy: thumbnail in its clay tone, name, part number, unit price, a + − stepper with the quantity between the buttons, the line total, and a trash-glyph remove button with an accessible name per product.
  • Order summary: Items, Subtotal, Shipping and Estimated total, with the free-shipping threshold stated as copy rather than colour, exactly as the board's footer does.
  • Extra line: the board shows two lines; the static variant keeps both and adds Silicon Nitride Kiln Bearing Set £18.40 so this page carries the spec's expected text bearing. Its subtotal and total therefore read £62.29 instead of the board's £43.89.
  • Static honesty: on cart.html the steppers, remove and checkout are disabled buttons — they are drawn to match the board and must not pretend to work. index.html is where the same drawer is live, persisted in localStorage, keyboard-operable, with focus returning to the control you used.
  • Contrast deviation: the board draws white labels on emerald buttons; the demo uses dark ink on the same emerald because white measures 2.6:1 there. The emerald itself is unchanged.
  • Not on the board: the drawer also carries the contract's "Add by part number" form (form#cart-form, fields item and an optional quantity), which board 2 does not depict.

Reference board

Live variant — 1280 × 900

Live variant — 390 × 844

  • Copy: the heading No ceramics match "porcelain teapot", the suggestion line and the "Reset search" action follow the board's wording; the query stays in the search field so the state is readable on its own.
  • Where it comes from: index.html reaches the same state by filtering — type or submit porcelain teapot and the twelve-card grid empties, the card appears and the results line reads No pieces match "porcelain teapot". empty.html is that state as static markup for comparison.
  • Static honesty: the chips on empty.html are disabled buttons; that page has no script, and the search form there submits to index.html?q=…, which really does filter the live grid.
  • Illustration: the shelf and bowl are drawn as SVG against the board's own picture, which is a generated raster.
