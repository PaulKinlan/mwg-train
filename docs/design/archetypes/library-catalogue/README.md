# Library catalogue — illustrative reservation-refusal visual reference

- **Archetype:** `library-catalogue`; the board illustrates `fam-16`'s family - a local archive and antiquarian book collection whose reservation is a reading-room appointment for a manuscript, with a validated reservation date ([`plan.md`](plan.md):26-27, [`plan.md`](plan.md):45). The two families sharing this archetype differ in subject, and this board is about the second of them: `tr-16` is the training family, the Heirloom Perennial Repository, a botanical cuttings and seed-strain index whose reservations are for cuttings by quantity, while `fam-16` (eval split) is the manuscript archive that carries the reservation-refusal assertions this board depicts ([`plan.md`](plan.md):133-137). Neither family is one of the five pilot families (`booking`, `contact-lead`, `catalogue`, `account-recovery`, `event-registration` in [`pilot/archetypes.mjs`](../../../../pilot/archetypes.mjs)), so this board follows the out-of-set wiring with no asset-store or pilot cascade. Its contract asserts a refusal: a reservation submitted without the researcher name, or with an invalid reservation date, is refused with an associated inline error message (`HTTP 400`), and announcing the error is part of the contract ([`plan.md`](plan.md):120, [`plan.md`](plan.md):133-137).
