## Local retention, not remote immutable storage

`node scripts/default-set-cordon.mjs <private-run-dir> <private-archive-root>` copies `run.json`, raw response when present, and project files without running them. It refuses stubs/other arms, symbolic links, mismatched or unpaired raw-response hashes, and archive roots inside this public checkout or a sibling worktree of the same public repository (including symlink aliases), **before creating any destination directory**. Its per-run manifest records source identities, caller-supplied versus resolved revision, decode/interface/prompt hashes, status (including failed generations), per-file SHA-256/bytes, and `excluded_from_training: true`. It checks both sides of the copy, seals local files 0400 and directories 0500, and verifies the manifest again on repeat without replacing anything. Tests cover success, failure without a project, corrupt retained file and symlink refusal.
